# Разовое исключение при архивировании t-4-docs

Дата: 2026-10-16 (Europe/Moscow).

После сообщения о блокировках archive gate пользователь явно указал:
«обойди проверки для этого чэенджа и заархивируй».
Исключение относится только к `t-4-docs`; общие правила, код gate, registry
и CI не изменяются.

Отдельным запросом в тот же день пользователь разрешил закоммитить и
замержить эти изменения с обходом штатного CI только для этого изменения.
Merge может использовать разовое административное исключение; это не
меняет фактический результат проверок и не является подтверждением PASS.

## Известные результаты и пропущенный допуск

- Все 12 задач отмечены выполненными; OpenSpec validation успешна.
- Документация и её review прошли проверку: восемь страниц и 15 Mermaid blocks.
- Сохранённый tooling report содержит 88 PASS; хэши проверенных исходников
  соответствуют текущим файлам. В отчёте нет `registry_sha256`, рядом нет
  обязательного `manifest.json`; полный regression gate этот формат не принимает.
- Имеющийся полный regression report относится к `t-3-persistent`, а не к
  `t-4-docs`, и не является подтверждением этого изменения.
- В текущем TamarixTests registry нет связей с восемью сценариями
  `project-documentation`. Их tooling traceability сохранена в `tasks.md`;
  это не заменяет связей registry, обязательных для штатного archive gate.
- Новый прогон тестов не выполнялся. PASS полного archive gate не получен
  и не заявляется; фиктивное regression evidence не создаётся.

## Способ архивирования

По разовому разрешению пользователя применяется прямой вызов OpenSpec
с обходом project wrapper и CLI validation, с синхронизацией delta specs:

```sh
openspec archive t-4-docs --yes --no-validate --json --store tamarix-specs
```

Основная спецификация `project-documentation` получает три требования
и восемь сценариев. Change переносится в
`openspec/changes/archive/2026-10-16-t-4-docs/`.

Этот документ фиксирует разрешённое исключение, а не успешное прохождение
штатных проверок. Существующий CI `archive-evidence` не поддерживает waiver
и отклонит такой новый архив без обязательного regression evidence.
