# Tamarix — спецификации и документация

Начните с [руководства проекта](docs/README.md): там описаны продукт,
архитектура, домены, сервисы, API, PostgreSQL и работа со средой.

Этот репозиторий — центральный OpenSpec Store `tamarix-specs`.
Требования находятся в [openspec/specs](openspec/specs/), изменения — в
[openspec/changes](openspec/changes/), правила проектирования и ADR — в
[openspec/context](openspec/context/README.md). Код сервисов хранится отдельно.

При подготовке изменений прочитайте [AGENTS.md](AGENTS.md).
Перед архивированием обновите документацию по
[процессу сопровождения](docs/development.md) и выполните
[проектные проверки archive](tools/ARCHIVE_GATE.md).
